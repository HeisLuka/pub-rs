# JSON-снимок CFB

Команда:

```bash
pub inspect <файл.pub> --json
```

выдаёт диагностический снимок контейнера CFB. На этом уровне вывод не содержит предположений о семантике Publisher.

## Схема версии 1

Верхний объект:

```json
{
  "schema_version": 1,
  "entries": []
}
```

Каждый элемент `entries` содержит:

- `path` — канонический абсолютный путь внутри CFB с разделителем `/`;
- `name` — имя записи, полученное из каталога CFB;
- `kind` — `root`, `storage` или `stream`;
- `len` — длина записи в байтах, которую сообщает CFB-слой.

## Детерминизм

Перед сериализацией элементы сортируются лексикографически по каноническому `path`.

Порядок, возвращаемый библиотекой обхода CFB, не является частью публичного JSON-контракта `pub-rs`.

Корневой элемент всегда имеет канонический путь `/`.

## Изменения схемы

Несовместимое изменение структуры JSON требует увеличения `schema_version`.

Добавление семантики Publisher в этот снимок не допускается. Для Contents, Quill и Escher будут отдельные структуры более высокого уровня.
